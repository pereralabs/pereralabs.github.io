BOX 04 · ARCHITECTURE HIGHLIGHT DYNAMIC DAILY ROLLOVER & FX LEDGER

Offline-First Currency & Daily Surplus Rollover

Travelers on tight budgets often keep cellular data off abroad. CheapoTrip caches exchange rates locally and dynamically recalculates your remaining daily allowance whenever you log under or over budget.

fun computeAdjustedDailyCap(trip: TripBudget, dayIndex: Int): Double {
  val spentSoFar = trip.entries.filter { it.day < dayIndex }.sumOf { it.amountHome }
  val daysLeft = (trip.totalDays - dayIndex).coerceAtLeast(1)
  return ((trip.totalCap - spentSoFar) / daysLeft).coerceAtLeast(0.0)
}

      val map = DataMapItem.fromDataItem(event.dataItem).dataMap
      fetchWatchWeather(map.getDouble("lat"), map.getDouble("lon"))
