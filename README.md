# Android Developer Portfolio

Two-page GitHub Pages portfolio:
- `index.html` — developer bio, technical background, design/content work and mission
- `apps.html` — Cloud Cover Seeker, Fake Call, Frugal Travel Planner, and Reduce Smoking
- `style.css` — shared responsive styling

## Personalize before publishing
Replace:
- Your contact email
- `YOUR-EMAIL@example.com`
- Google Play links
- GitHub/project links

You can also add screenshots, app logos, technology stacks and demo links to each project card.

## GitHub Pages
1. Create a GitHub repository.
2. Upload the files to the repository root.
3. Go to Settings → Pages.
4. Select Deploy from a branch.
5. Choose `main` and `/ (root)`.
6. Save.
